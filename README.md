# Log Uploader Engine & REST API

**[Source](https://github.com/elPescad/telemetry-analytics/tree/master/app)**

A high-performance analytics processor, reporting engine, and REST API built with **Python**, **Polars**, **FastAPI**, **APScheduler**, **Google Cloud Storage (GCS)**, **Supabase PostgREST**, and **FPDF2**. This downstream engine consumes compressed telemetry log archives generated by a high-concurrency Rust ingestion broker, vectorizes NDJSON payloads, computes decay-weighted engagement metrics, hydrates UUIDs via batch REST lookups, and exposes authenticated endpoints for frontend consumption and PDF exports.

## Key Modules & Core Functions

| Module | Core Purpose | Key Functions & Implementation Highlights |
| :--- | :--- | :--- |
| `app/models.py` | Type-Safe Event Container | Defines `TelemetryRegistry` using `@dataclass(frozen=True, slots=True)` to segregate events into categorized DataFrames (`posts`, `events`, `feed_ui`, `sessions`, `other`). |
| `app/parser.py` | Cloud Log Parser & Vectorizer | In-memory decompression of GCS `.log.gz` blobs. Uses Polars' native `str.json_decode` with explicit `Struct` schemas to decode JSON at C-speed. |
| `app/analytics.py` | Metrics Computation Engine | Calculates user scores, event turnouts, and post engagement rates. Explodes and deduplicates user UUID lists (`list.explode().unique()`) across multi-week rollups. |
| `app/enrichment.py` | PostgREST Metadata Hydrator | Zero-dependency batch metadata loader using standard library `urllib.request`. Resolves UUIDs to display names, event titles, and content snippets via Supabase. |
| `app/pdf_generator.py` | Executive PDF Layout Engine | Custom `FPDF2` report layout with manual pagination controls, fallback UTF-8 sanitization (`latin-1` replacing), and alternate row shading. |
| `api.py` | REST API & Task Scheduler | FastAPI app with `X-API-Key` header authentication, background startup initialization (`asyncio.to_thread`), and midnight UTC cron triggers via `APScheduler`. |

## Analytics Formulas & Scoring Logic

### 1. Weighted Student Engagement Score
Scores evaluate user participation across high-intent and low-intent actions:

$$\text{Score} = (\text{Events Attended} \times 15) + (\text{Posts Created} \times 5) + (\text{Likes Cast} \times 1)$$

### 2. Event Turnout Conversion Percentage
Measures actual attendance verified via QR code scans against submitted RSVPs:

$$\text{Turnout \%} = \left( \frac{\text{Actual QR Scans}}{\text{Total RSVPs}} \right) \times 100$$

### 3. Post Engagement Rate
Evaluates post interaction quality relative to impression views:

$$\text{Engagement Rate \%} = \left( \frac{\text{Likes} + \text{Comment Views}}{\text{Total Post Views}} \right) \times 100$$

## REST API Reference

### `GET /analytics`
* **Authentication:** Required (`X-API-Key` header)
* **Description:** Serves the primary enriched JSON analytics payload containing user leaderboards, weekly summaries, and monthly stats.
* **Cache Header:** `Cache-Control: public, max-age=300`
* **Status Codes:** `200 OK`, `403 Forbidden`, `503 Service Unavailable` (Cache warming)

### `GET /analytics/pdf`
* **Authentication:** Required (`X-API-Key` header)
* **Description:** Returns the rendered monthly executive PDF report. Triggers on-the-fly generation if missing.
* **Content-Type:** `application/pdf`
* **Status Codes:** `200 OK`, `403 Forbidden`, `503 Service Unavailable`

## Quickstart & Server Deployment

```bash
# 1. Clone repository and install dependencies
git clone [http://github.com/elPescad/tiered-telemetry-stream.git](http://github.com/elPescad/tiered-telemetry-stream.git)
cd tiered-telemetry-stream
pip install polars fastapi uvicorn apscheduler google-cloud-storage fpdf2 python-dotenv

# 2. Configure environment
export API_SECRET_KEY="your-secure-api-key"
export GCP_BUCKET_NAME="your-gcs-bucket"
export SUPABASE_URL="[https://your-project.supabase.co](https://your-project.supabase.co)"
export SUPABASE_KEY="your-supabase-service-key"

# 3. Launch the API server
uvicorn api:app --host 0.0.0.0 --port 8000
```

### Verification Calls
```bash
# Fetch Analytics JSON
curl -H "X-API-Key: your-secure-api-key" http://localhost:8000/analytics

# Download Monthly PDF Summary
curl -H "X-API-Key: your-secure-api-key" http://localhost:8000/analytics/pdf --output Summary.pdf
```
